ABOUT THIS PROJECT

The midnight field
dossier system

A personal, anime-styled command deck for CS2 statistics — built on top of real CSStats pages and kept fully self-hosted in a plain-data registry.

  • 01 · DATA SOURCENumbers mirror each player's CSStats page. A live CSStats pull is attempted first; when the API is unreachable (auth, CORS, offline), the local snapshot renders instead — the profile never breaks.
  • 02 · AVATARSProfile pictures resolve from Steam's CDN first, then CSStats, then a local placeholder. External outages degrade gracefully.
  • 03 · PLAYERSThe registry in data/players.js is the single source of truth. Add a player once — search, profiles, compare and widgets all pick them up automatically.
  • 04 · EXTENSIONSEmbeddable stat widgets, a weighted comparison engine, five color themes, and a dedicated dossier for Arshi ship in the same three-file stack.
